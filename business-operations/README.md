# أدوات تشغيل الأعمال — MT Software Solutions

هذه مواد خاصة قابلة للتعديل، مستبعدة من البناء العام. لا تحتوي على بيانات عميل فعلية أو أسعار أو سياسات معتمدة. لا تنشر هذا المجلد. النسخة الحالية مسودات للاستخدام والمراجعة الداخلية.

## بدء الاستخدام

1. اختر مسؤولًا عن استقبال الطلبات وسجل كل استفسار في **operations.xlsx → Opportunities** بمعرّف ثابت ومصدر معروف أو Unknown. ابدأ من New inquiry وحدد Next action وNext action date.
2. استخدم 01-qualification.md لتأهيل الاحتياج، ثم 03-discovery-scope.md لتحديد المخرجات والحدود. لا تطلب كلمات مرور أو ملفات سرية في الاستفسار الأول.
3. انسخ ورقة Project estimate لكل مشروع. أدخل ساعات العمل وتكلفة الساعة الداخلية والتكاليف الخارجية؛ الصفر يعني «لا توجد تكلفة» والخلية الفارغة تعني «غير معروف». لا تعتمد عرضًا قبل اكتمال التقدير ومراجعة الافتراضات.
4. جهز العرض باستخدام 04-proposal.md. سجل تاريخ إرسال العرض، ولا تعده بيعًا. عرّف معيار Won داخليًا، وسجل دليل الاتفاق. سجّل تحصيل الأموال منفصلًا في Collections.
5. استخدم قائمة التسليم ونموذج التغيير أثناء التنفيذ. انقل التقدير النهائي والتكلفة الفعلية والإيراد إلى Project results، مع نسخة النطاق والملاحظات. لا تخلط هامش المشروع بصافي ربح الشركة.
6. استخدم Cohort metrics لمجموعة استفسارات محددة وتاريخ قطع واحد، وراجع دليل المؤشرات. اختبر التسويق بعد جاهزية مسار التواصل، دون نشر أو إنفاق قبل تفويض خاص.

## الحدود والنسخ

يوفر الملف 100 صف لكل سجل. أضف الصفوف داخل جدول Excel وامتد الصيغ والتحقق إلى النطاق الجديد قبل استخدام أكثر من 100 صف؛ ورقة المؤشرات يدوية ولا تتوسع تلقائيًا. لا تجمع عملات مختلفة، ولا تحول قيمة مجهولة إلى صفر. خذ نسخة مؤرخة قبل تحديث سجل حقيقي. ارفع النسخ إلى تخزين خاص بصلاحيات محدودة وفق سياسة احتفاظ تعتمدها الشركة.

تحققت الصيغ وتغير المدخلات والفراغ والصفر والتصدير في محرك Artifact Tool. لم تُختبر نسخة Microsoft Excel الأصلية على هذا الجهاز. المجلد لا يحل محل العقود أو النظام الداخلي القائم؛ يمكن مواءمة الحقول معه لاحقًا.
