# تقدير التكلفة والنتائج

Project estimate يجمع سبعة أنواع جهد: التحليل، التصميم، التطوير، الاختبار، إدارة المشروع، المراجعة والتسليم، والمراجعات المتوقعة. أدخل ساعات ومعدل تكلفة داخلية لكل نشاط، ثم التكاليف الخارجية المقدرة والفعلية. استخدم عملة واحدة في النسخة؛ لا توجد معدلات أو أسعار مفترضة.

المعدل الداخلي هو تكلفة الساعة على الشركة، مع تحديد ما إذا كان يشمل الأجور والتكاليف غير المباشرة الموزعة. لا يساوي سعر البيع. إذا كان نشاط غير مطلوب، أدخل ساعات 0 ومعدلًا رقميًا معلومًا (أو 0 عند انعدام التكلفة). إدخال صفر رقمي مطلوب للتكلفة الخارجية غير الموجودة. مجموع تكلفة غير مكتمل يظل فارغًا حتى اكتمال جميع الصفوف حتى لا يخفي جهدًا مجهولًا.

- التكلفة المقدرة = مجموع الساعات المقدرة × المعدلات الداخلية + التكاليف الخارجية المقدرة.
- التكلفة الفعلية = ساعات العمل الفعلية × التكلفة الفعلية للساعة + المصاريف الخارجية الفعلية.
- مساهمة المشروع = الإيراد المعترف به − تكلفة التنفيذ الفعلية. لا تساوي تحصيل النقد ولا صافي ربح الشركة.
- هامش المشروع = المساهمة ÷ الإيراد. الإيراد الصفري يعرض n.a. لا 0%.
- تجاوز الجهد / التكلفة = (الفعلي − المقدر) ÷ المقدر. المقام الصفري يعرض n.a. والمفقود يبقى فارغًا.

نهاية المشروع: احتفظ بنسخة التقدير والافتراضات ثم سجل قيمتها في Project results مع Project ID ونسخة النطاق. سجل أسباب التجاوز؛ افصل أثر التغييرات المعتمدة عن أخطاء التقدير. التحصيل يتصل بورقة Collections بالمعرّف والعملة وحالة Received فقط. لا تجمع عملات مختلفة ولا تعتمد الإجمالي قبل اكتمال مراجع التحصيل.

الورقة الحالية لا تحسب ضرائب أو ربح الشركة العام أو FX أو تسعيرًا تلقائيًا. يحدد المالك السياسات قبل استخدام العرض التجاري.
