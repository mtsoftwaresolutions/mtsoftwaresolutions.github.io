# متابعة الفرص والتحصيل

Stages في ورقة Opportunities: New inquiry → Initial contact → Qualified opportunity → Scope definition → Proposal sent → Won أو Lost.

| المرحلة | دليل الانتقال |
|---|---|
| New inquiry | وصول طلب ومعرّف ومصدر ومسؤول وخطوة تالية |
| Initial contact | تواصل بشري أول مسجل في First contact at |
| Qualified opportunity | مراجعة مكتملة واحتياج مناسب موثق في Qualified at |
| Scope definition | تحديد مخرجات وحدود وتبعيات ومسؤول اعتماد |
| Proposal sent | عرض محدد النسخة وتاريخ إرسال وقيمة وعملة إن كانا معروفين |
| Won | تحقق معيار الفوز الذي تعتمد الشركة؛ اكتب دليل الاتفاق في Won criterion evidence |
| Lost | قرار نهائي معروف وتاريخه وسببه المعروف؛ استخدم Unknown إذا لم يُعرف السبب |

احتفظ بتواريخ المراحل عند تقدم الحالة أو إعادتها؛ الحالة الحالية وحدها لا تكفي لحساب الانتقال التاريخي. الفرصة المفتوحة ليست خسارة، وProposal sent ليس بيعًا، وWon لا يعني تحصيلًا. لا تتجاوز السعر أو سعة التنفيذ بالاستنتاج من حالة السجل.

Source = القناة؛ Source detail / campaign = مصدر محدد أو معرّف التجربة. Audience يحتفظ بالفئات السبع الحالية. Service يحتفظ بالمعرّفات الثمانية. Engagement path = scope / build / operate. Client ID يمنع عد العميل نفسه أكثر من مرة في اكتساب العملاء. Cohort تحدد مجموعة الاستفسارات التي تتبع معًا. New client? وMaintenance / repeat? لا يُستنتجان تلقائيًا.

Response hours تحسب الساعات المنقضية بين Received at وFirst contact at. أدخل توقيتًا موحدًا معلنًا؛ الصيغة لا تستبعد الليل/العطلات. القيم السالبة تعرض Invalid dates. راجع الفرص بدون Next action أسبوعيًا، وحدد موعدًا ومسؤولًا بدل إغلاقها بلا قرار.

Collections: كل صف تحصيل بمعرّف فريد وProject ID ومبلغ وعملة وتاريخ ومرجع. Planned يصف مبلغًا منتظرًا، Received مبلغًا وصل فعلًا، Cancelled استحقاقًا ملغى. لا تسجل Received دون تاريخ وإثبات أو دون مبلغ رقمي. لا تكرر معرّف التحصيل. Project results تجمع Received فقط عند تطابق المشروع والعملة. عدم وجود سجل لا يعني صفرًا مؤكدًا. Record status يوضح نقص بيانات التحصيل أو معرّفًا مكررًا، ويعرض Project results عندها Review collections بدل إجمالي مضلل. راجع القيم الناقصة والمعرّفات المكررة قبل استخدام الإجمالي.
